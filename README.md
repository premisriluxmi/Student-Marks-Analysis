# Student Marks Analysis

A beginner-level Python project that analyzes student marks and calculates basic statistical values.

## Objective

To analyze a list of student marks using Python and calculate:

- Total marks
- Average marks
- Highest mark
- Lowest mark

## Technologies Used

- Python 3
- Jupyter Notebook

## Python Functions Used

- `sum()` – to calculate total marks
- `len()` – to find the number of students
- `max()` – to find the highest mark
- `min()` – to find the lowest mark

## Results

|   Analysis   | Result |
|--------------|-------:|
| Total Marks  |   819  |
| Average Marks|  81.9  |
| Highest Mark |   95   |
| Lowest Mark  |   67   |

## How to Run

1. Open the `Student_Marks_Analysis.ipynb` file in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. View the calculated results.
